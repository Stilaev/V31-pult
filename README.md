# V31 Пульт — планшет вместо компьютера для Roland V31

Приложение для планшета на Android и iPad, которое управляет модулем Roland V31 (V-Drums 3 Series) по Bluetooth MIDI или кабелем USB. Повторяет возможности V31 Editor, которые Roland открыл в протоколе модуля.

## Что умеет

| Раздел | Что можно делать |
|---|---|
| Киты | Список 200 китов с именами, переключение, копирование кита в другой номер, резервные копии китов в планшете и в файлах |
| Пэды | Для каждой зоны (голова, обод, край, купол, кросс-стик): три слоя — инструмент, громкость, pitch, decay, транзиент, EQ слоя, слои по силе удара, V-EDIT. Громкость и посылы зоны, mute group, position, pedal bend, EQ пэда, панорама, компрессор пэда, шины и сайдчейн. Прослушивание зоны с планшета |
| Микшер | Фейдеры громкости всех пэдов, кита и педали хай-хэта, панорама, посылы в эмбиенс |
| Эффекты | 8 Bus FX (4 шины × 2 эффекта, 95 типов) со всеми параметрами, уровни шин, сайдчейн, маршрутизация пэдов и шин, Bus Reverb |
| Эмбиенс | Overhead (вместе с фильтрами), Room, Reverb, Kit Resonance |
| Настройки кита | Имя и подпись, громкость, темп кита, фраза, цвет кнопок, кросс-стик, щётки, страйнер, buzz, компрессор и EQ кита, KIT MIDI |
| Триггеры | 16 банков: тип пэда и все параметры аналоговых входов, цифровые пэды, хай-хэт, подавление перекрёстных помех |
| Сет-листы | 32 сет-листа: название и до 32 шагов |
| Система | Выходы, метроном (звук и уровень), Mix In / Bluetooth / USB-аудио, настройки приложения |
| Монитор | Сила ударов по пэдам, журнал обмена с модулем |

«Голова+обод: вместе» меняет голову и обод одновременно, как кнопка H&R на модуле. При выборе инструмента ободу подставляется парный (S → SR, Rd → RdE и RdB).

«Отменить» в шапке возвращает все значения кита, прочитанные при его загрузке.

## Чего нет и почему

Roland не открыл эти функции в MIDI-протоколе V31, поэтому их нет и в приложении:

- метроном вкл/выкл, общий темп, размер (есть только темп кита);
- coach mode, проигрыватель и рекордер;
- импорт своих сэмплов, картинки китов, установка расширений Roland Cloud, прошивка — это делается через V31 Editor на компьютере или Roland Cloud Connect.

Wi-Fi модуля закрыт: его использует только Roland Cloud Connect, протокол не опубликован. Поэтому связь — Bluetooth MIDI или USB.

## Что сверить на модуле в первый день

Протокол взят из официальных документов Roland: V31 MIDI Implementation 2.00 и V31 Data List. Адреса, команды и контрольные суммы проверены на примерах из документации. Несколько вещей документ не описывает однозначно — их нужно проверить на модуле:

1. **Отрицательные значения.** Измените на планшете панораму пэда на L10 и посмотрите на модуль. Если там R-сторона или что-то странное, переключите «Система → Кодировка отрицательных значений».
2. **Параметры эффектов, V-EDIT, Room/Reverb, компрессоров.** В протоколе они называются «Parameter 1…40»; названия и шкалы взяты из Data List по порядку. Сверьте пару параметров с экраном модуля.
3. **Тип пэда (Trig Type)** — порядок взят из таблицы Data List.
4. **Инструменты из расширений и пользовательские сэмплы** показываются как «Банк · номер»: Roland не опубликовал их нумерацию.

Удобнее всего сверять так: на модуле включите MENU → SYSTEM → MIDI → BASIC → Transmit Edit Data = ON. Крутите параметр на модуле — в «Мониторе» приложения будет видно, какой адрес и какое значение пришло. Если что-то не совпадает, пришлите строки из журнала (кнопка «Сохранить журнал»).

«Инженерный режим» в «Системе» показывает у каждого параметра адрес и «сырое» значение, а у эффектов и V-EDIT — все параметры, включая неподписанные.

## Подключение

**Bluetooth.** На модуле: MENU → SYSTEM → Bluetooth → Bluetooth MIDI = ON. В приложении: «Не подключено» → «По Bluetooth» → «V31 MIDI». Не подключайтесь к «V31 MIDI» из системных настроек Bluetooth планшета: Roland пишет, что так связь может работать неправильно.

**USB.** Порт USB COMPUTER модуля → планшет (USB-C или переходник OTG) → «Кабелем USB».

Пока пульт подключён, V-Drums Play и V31 Editor к модулю не подключайте.

**На модуле** в MENU → SYSTEM → MIDI → BASIC должно быть Receive Exclusive = ON (иначе модуль не принимает команды пульта). Device ID в «Системе» приложения должен совпадать с Device ID модуля (по умолчанию 17).

**Демо.** Без модуля выберите «Демо без модуля»: виртуальный V31 отвечает на все запросы. Тот же интерфейс открывается в браузере: `web/index.html?demo`. В Chrome на компьютере с модулем по USB работает и вариант «MIDI этого компьютера».

## Как получить приложение

### Android: APK через GitHub (без установки программ)

1. Создайте на github.com новый репозиторий, например `V31-remote-control`.
2. Загрузите в него **всё содержимое** этой папки, вместе со скрытой папкой `.github`.
3. Вкладка Actions → «Android APK» запустится сама (3–6 минут).
4. В разделе Releases появится `V31-Pult.apk`. Скачайте его на планшет и откройте; Android попросит разрешить установку из этого источника.

Или в Android Studio: File → Open → папка `android` → Run.

### iPad

Apple не даёт ставить приложения мимо App Store без подписи Apple ID. Варианты:

**Через Mac с Xcode (бесплатный Apple ID, подпись на 7 дней):**
```
brew install xcodegen
cd ios
xcodegen generate
open V31Pult.xcodeproj
```
В Xcode: Signing & Capabilities → Team → ваш Apple ID. Подключите iPad кабелем, выберите его и нажмите ▶. На iPad: Настройки → Основные → VPN и управление устройством → доверять разработчику. Через 7 дней повторить ▶ (с платной учётной записью разработчика — на год, можно через TestFlight).

**Без Xcode:** GitHub Actions («iPad IPA») собирает `V31-Pult-unsigned.ipa` в Releases. Его подписывает и ставит на iPad программа Sideloadly или AltStore с вашим Apple ID.

## Устройство проекта

| Путь | Что внутри |
|---|---|
| `web/` | Интерфейс и протокол — общий для Android и iPad |
| `web/core.js` | Адресная карта, SysEx RQ1/DT1, кодирование значений, очередь обмена, эмулятор модуля |
| `web/app.js` | Экраны пульта |
| `web/data.js` | Карта параметров, инструменты, параметры эффектов — сгенерировано из PDF Roland |
| `web/typed.js` | Названия обобщённых параметров (V-EDIT, Reverb, Room, компрессоры) и список типов пэдов |
| `android/` | Оболочка Android: WebView + MidiManager (Bluetooth MIDI, USB) |
| `ios/` | Оболочка iPad: WKWebView + CoreMIDI, окно Bluetooth MIDI, проект для XcodeGen |
| `tools/` | Скрипты, которые строят `web/data.js` из PDF Roland |
| `tests/` | Проверка протокола (`node tests/protocol.test.js`) и интерфейса в демо (`python3 tests/ui_smoke.py`) |

Пересобрать данные после новой версии документов Roland:
```
cd tools
pdftotext -layout V31_MIDI_Implementation_eng01_W.pdf midi.txt
python3 build_data.py midi.txt V31_DataList_eng02_W.pdf ../web/data.js
```
